# Print with New Line

![Difficulty](https://img.shields.io/badge/Difficulty-Basic-red)

## Problem

There is a string  " **Geeks for Geeks"**, print each word on a separate line.

 **Note:** No input required for this problem.

 **Example :** 

```
Input: Not Required
Output: Geeks
        for
        Geeks
Explanation: Each word is printed on a separate line.
```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-23T16:02:27.773Z  

```py
print("Geeks\nfor\nGeeks")
```
