# Input Boolean Value

![Difficulty](https://img.shields.io/badge/Difficulty-Basic-red)

## Problem

Take a boolean value  **a**  as an input. The program should display its numeric representation:

- 1 for "true"
- 0 for "false"

 **Examples:**  

```
Input: a = true
Output: 1
```

```
Input: a = false
Output: 0
```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-04T12:40:49.742Z  

```py
a=input()
if a=="true":
    print(1)
else:
    print(0)
```
